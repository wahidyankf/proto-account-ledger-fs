# Specifications

The shared description of what this repository's software is expected to do. Specifications describe the system as
built, separate from the code, so a change can be discussed from one source of truth. Behaviour is specified by the
plain pytest tests that prove it, not here; there is no `behaviours/` tree.

A specification owner lives at `specs/apps/<product>/<owner>/` and holds a `README.md` and an `architecture.md`.
