# Ideas

Two-page briefs, one `<slug>.md` file each. An idea argues that a problem is worth solving; it does not design the
solution. A ripe idea is promoted into a full plan in [`backlog/`](../backlog/README.md) through
[plan-ideas-grooming](../../repo-governance/workflows/plan/plan-ideas-grooming.md).

See the [idea brief template](../../repo-governance/conventions/structure/plans/015-idea-brief-template.md).
