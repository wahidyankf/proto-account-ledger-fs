# Backlog

Full six-document plans that are prepared but not started. Starting one requires a current `PASS` from
[plan-quality-gate](../../repo-governance/workflows/plan/plan-quality-gate.md), run when the owner asks for it.

A plan is never executed out of this folder. Move it to [`in-progress/`](../in-progress/README.md) first, and push that
move before touching anything else.
