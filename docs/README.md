# Documentation

Human-facing documentation, organized by the Diátaxis framework: each section answers one kind of need. Rules for agents
and people live in [repo-governance/](../repo-governance/README.md); behaviour specifications live in
[specs/](../specs/README.md).

## Directory Map

- [Tutorials](tutorials/README.md) — learning by doing, start to finish.
- [How-To Guides](how-to/README.md) — steps for one task.
- [Reference](reference/README.md) — exact facts to look up.
- [Explanation](explanation/README.md) — why the design is the way it is.
